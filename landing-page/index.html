The problem

University students often miss important announcements, deadlines, project updates, and campus events because information is distributed across LINE, Facebook Groups, Messenger, email, learning management systems, and personal notes.

The solution

CampusLife Hub provides a centralized and mobile-friendly platform where students can access announcements, events, project resources, search for information, and view useful dashboard summaries.

Key prototype features

Centralized Announcements

View important campus and academic announcements in one organized location.

Events and Deadlines

Access upcoming campus events, academic dates, and important deadlines.

Project Resources

Find project information and access important shared resources without searching through old chat messages.

Search and Dashboard

Search for relevant information and view a summary of campus and project activities.
