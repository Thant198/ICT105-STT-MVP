The prototype was developed using **HTML, CSS, and JavaScript** as a front-end MVP prototype.

The system demonstrates the complete user flow from the landing page to the login page, homepage, announcements, events, projects, search, dashboard, and admin page. All data shown in the prototype is simulated for demonstration and academic purposes only.
