# Initial IT Venture Idea Log

## Idea 1

### Problem Area
University students receive announcements, events, project updates, and academic information through multiple platforms, making it difficult to stay informed and organized.

### Target Users
- University students
- Student organizations
- Campus administrators

### Current Alternative
Students currently rely on social media groups, email, messaging applications, and learning management systems to obtain campus information.

### Proposed IT Solution
Develop **CampusLife Hub**, a web-based platform that centralizes announcements, events, projects, and campus information into one system.

### Possible Technology
- HTML
- CSS
- JavaScript
- GitHub
- Local Storage
- Cloud Hosting

### Why This is Suitable
The project is practical, solves a real problem experienced by university students, and can be developed as a web-based MVP during the semester.

## Idea 2

### Problem Area
Students often have difficulty finding available study rooms, laboratories, and campus facilities because booking information is not centralized.

### Target Users
- University students
- Lecturers
- Campus staff

### Current Alternative
Students ask friends, visit facilities directly, or contact staff to check room availability.

### Proposed IT Solution
Develop a **Campus Facility Booking System** that allows users to check availability and reserve campus facilities online.

### Possible Technology
- HTML
- CSS
- JavaScript
- Database
- Cloud Hosting

### Why This is Suitable
The system solves a common campus problem and can be demonstrated as a functional web prototype.

---

## Idea 3

### Problem Area
Students often struggle to find suitable teammates for group assignments because there is no centralized collaboration platform.

### Target Users
- University students
- Student project teams

### Current Alternative
Students rely on class chat groups or personal connections to form teams.

### Proposed IT Solution
Develop a **Student Team Matching Platform** where students can create profiles, join projects, and find teammates based on skills and interests.

### Possible Technology
- HTML
- CSS
- JavaScript
- Database
- Cloud Hosting

### Why This is Suitable
The project has clear user value, is technically feasible within one semester, and demonstrates practical software development skills.
