# User Testing Plan

## 1. Testing Objective

Evaluate whether users can easily understand the purpose of CampusLife Hub, navigate the prototype, access campus information, and complete common tasks without assistance before Lab 14.

## 2. Test User Profile

| User Type | Number of Testers | Why This User Type Matters |
| --- | --- | --- |
| University students | 5 | Primary users who will use the system to access announcements, events, and project information. |
| Campus administrator | 1 | Represents the user responsible for managing announcements, events, and campus information. |

## 3. Testing Tasks

| Task ID | User Task | Related Requirement | Success Criteria | Observation Focus |
| --- | --- | --- | --- | --- |
| T01 | Open the landing page and explain the purpose of CampusLife Hub. | FR-01 | User correctly explains the system purpose. | Understanding of the value proposition. |
| T02 | Log in to the prototype. | FR-02, FR-03 | User logs in successfully without assistance. | Login form clarity and validation. |
| T03 | View announcements, events, and project information. | FR-04, FR-05, FR-06 | User can locate the required information. | Navigation and usability. |
| T04 | Search for campus information and access the dashboard. | FR-07, FR-08 | User successfully finds relevant information and understands the dashboard. | Search effectiveness and dashboard clarity. |
| T05 | Access the admin page and identify its purpose. | FR-09 | User understands the admin functions. | Navigation and feature understanding. |

## 4. Testing Procedure

1. Introduce the purpose of the usability test.
2. Ask each participant to complete the testing tasks independently.
3. Observe user interactions without providing assistance unless necessary.
4. Record task completion, comments, and usability issues.
5. Collect overall feedback and suggestions for improvement.

## 5. Ethical Reminder

Do not collect unnecessary personal information. Inform participants that the prototype is developed for academic purposes only and that all feedback will be used solely for improving the CampusLife Hub prototype.
