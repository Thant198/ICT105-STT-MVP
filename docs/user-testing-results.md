# User Testing Results

## 1. Testing Summary

- Date: 30 July 2026
- Number of testers: 5 university students
- Prototype link: https://thant198.github.io/ICT105-STT-MVP/prototype/
- Testing location/platform: ICT Building Computer Lab / Desktop Web Browser

| Task ID | Task | Completed? | Main Issue Found | Evidence / Comment |

## 3. Common Usability Issues

| Issue ID | Issue Description | Severity | Related Requirement | Proposed Fix |
| --- | --- | --- | --- | --- |
| UI-01 | Some navigation labels were not immediately clear to users. | Important | FR-04, FR-05, FR-06 | Use clearer menu labels and add simple icons. |
| UI-02 | Search and filter controls need clearer instructions. | Important | FR-07 | Add placeholder text and rename the filter controls more clearly. |
| UI-03 | Dashboard metrics need more descriptive labels. | Useful | FR-08 | Rename the metrics and add short explanations. |
| UI-04 | The admin page does not clearly explain the administrator role. | Useful | FR-09 | Add an admin page heading and a short description of its functions. |

## 4. User Feedback Summary

Users liked the clean interface, simple page layout, and centralized access to announcements, events, and project information.

Some testers were initially unsure about the search filters, dashboard labels, and the purpose of the admin page.

Users suggested adding clearer navigation labels, more descriptive dashboard titles, simple icons, and short instructions for the search and admin features.

## 5. Evidence-Based Decision

- Ready for final improvement

Most testers completed the main CampusLife Hub tasks successfully. The main prototype flow worked correctly, including login, navigation, search, dashboard access, and admin-page access.

The identified problems are mainly related to unclear labels and short explanations. These are minor usability issues that can be improved before Lab 14 without changing the main system requirements or prototype structure.
