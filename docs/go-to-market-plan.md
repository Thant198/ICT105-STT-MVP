# Digital Go-to-Market Plan

## Product / Prototype Name
Campus Life Hub - Assignment & Project Tracker

## Target Early Users
ICT students in 1st and 2nd year courses who handle multiple programming, UI/UX, and database assignments every week.

## Main Value Proposition
Streamline your academic workload by tracking all assignment deadlines and progress statuses in one unified student dashboard.

## Channel Plan

| Channel | Target User | Message Angle | User Action Expected | Metric to Track | Why This Channel Fits |
| --- | --- | --- | --- | --- | --- |
| Class Chat Group | ICT Course Classmates | Stay organized and never miss project deadlines | Click demo link | CTA Clicks / Demo Visits | Direct line to students currently taking the same courses |
| Campus Poster QR | University ICT Building Students | Quick access to track and manage student assignments | Scan QR Code | QR Scans / Page Views | Contextually placed near lecture rooms and computer labs |
| Student Social Media | ICT Student Community | Clean and modern tool to boost academic productivity | Visit landing page | Page Views / Interest Rate | High daily engagement channel among tech-savvy students |

## Launch Sequence
1. Deploy landing page with working CTA connected to the live prototype.
2. Share the landing page link across class chat groups and student social channels.
3. Track visitor engagement, CTA clicks, and demo interactions.
4. Collect feedback via user testing and short forms.
5. Refine task features and user interface based on student feedback.

## Risk and Mitigation
- Risk: Low initial engagement due to student preference for existing chat apps.
- Mitigation: Highlight immediate value (e.g., instant search and status tracking) and place QR posters directly in ICT study areas.
